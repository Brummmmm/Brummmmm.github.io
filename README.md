# bdehaas.nl

Personal portfolio of **Bram de Haas** — Information Science student at Utrecht University, working across video editing, graphic design, photography, and web development.

Live at [bdehaas.nl](https://bdehaas.nl).

## About

Single-page portfolio site covering:

- **About** — background, studies, and roles (Sticky board, Summer Sports Week, festival work)
- **What I Do** — video editing reels, graphic design (logos, posters, visual identities), and web development projects
- **Contact** — ways to get in touch

## Tech stack

Plain HTML, CSS, and vanilla JavaScript — no build step, no frameworks. Fonts loaded from Google Fonts (Bricolage Grotesque, DM Sans).

## Structure

```
index.html      Page markup and content
style.css       Styling
Files/
  branding/     Logo and favicon
  photos/       About-section and personal photos
  designs/      Graphic design work
  designs-in-the-wild/   Designs shown in real-world use
  web/          Screenshots of web projects
```

## Deployment

Hosted via GitHub Pages with a custom domain (see `CNAME`). Pushing to `main` deploys automatically — no build process required.
